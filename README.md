# Botshelo Link

Intelligent medicine stock tracking and redistribution platform for **Kweneng East District, Botswana**.

## Features

- **Patient View** — Search essential medicines across 6 health facilities with real-time availability
- **DHMT Admin Dashboard** — District-level oversight with interactive map, inter-clinic transfer management, and risk filtering
- **Clinic Staff Portal** — OCR-powered stock capture, manual entry, and full audit trail
- **Data Sources** — 12 integrated datasets (WHO, NASA, World Bank, OpenStreetMap, etc.)
- **Climate-Driven Forecasting** — AI-powered demand prediction with heatwave scenario modeling

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS 4
- Lucide React icons
- Hash-based routing (no server required)

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deploy to Vercel:
```bash
npx vercel --prod
```
